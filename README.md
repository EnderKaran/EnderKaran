### 🏆 Featured Projects & Architecture

Here are some of the systems and ecosystems I've architected:

* 🍔 **Smash'd Burger V2.0 (Enterprise SaaS):** A full-stack AI-integrated restaurant management system. Features include an "AI Chef" for strategic analysis (LangChain), a custom *Take-over* algorithm for shift conflict resolution, and real-time kitchen displays. Built with **Next.js 15, Supabase, and Tailwind**.
* 📦 **ek-viewport (Open Source NPM Package):** A high-performance React utility package published globally to solve complex viewport management and responsive rendering issues, heavily focusing on Developer Experience (DX).
* 🧭 **Waypoint (Challenge.io Ecosystem):** A modular frontend architecture focusing on parallel data fetching (`Promise.all`) and high-resolution UI optimizations (Retina/@2x displays) for flawless state management.
* 🖌️ **SVG-Flow (In Development):** A core-logic architecture designed to convert SVG code into optimized React components, featuring a modern, dark-mode DevTools aesthetic.
